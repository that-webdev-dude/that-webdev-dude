Software developer. Mostly web stuff, occasionally things that probably shouldn't be running in a browser.

I work with TypeScript, React, Java and Spring Boot, with a background in scientific computing, seismic processing and data visualisation.

Lately I've been spending a questionable amount of free time building a 2D game engine, experimenting with graphics programming and generally making life more complicated than it needs to be.

Away from the keyboard, I'm usually skateboarding, listening to music or enjoying the outdoors.

## Side projects

### [NGNE](https://github.com/that-webdev-dude/ngne)

A 2D game engine built from scratch with TypeScript and WebGPU. ECS, fixed-step simulation, sprite rendering and zero runtime dependencies.

Started as a way to understand how game engines work. Got a little out of hand.

### [NGNE Sprite Editor](https://github.com/that-webdev-dude/ngne-sprite-editor)

A browser-based pixel art editor inspired by Aseprite, with layers, animation frames, onion skinning and NGNE-powered rendering.

Built to make artwork that actually looks the same in the editor and the game.

### [devkit-ts](https://github.com/that-webdev-dude/devkit-ts)

A TypeScript project scaffolding CLI. React, vanilla TS, libraries, build tooling and tests without the usual setup routine.

Because writing boilerplate once was enough.
